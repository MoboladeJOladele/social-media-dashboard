# Social Media Dashboard with Theme Switcher

A responsive social media dashboard built as part of a Frontend Mentor challenge. This project focuses on creating a clean, modern UI with support for light and dark themes, responsive layouts, and interactive hover states.

![Project Screenshot](./preview.jpg)

## 🔗 Links

* **Live Site:** https://social-dashboard-app.pages.dev/
* **Repository:** https://github.com/MoboladeJOladele/social-media-dashboard

## 🚀 Built With

* HTML5
* CSS3
* JavaScript (ES6)
* CSS Grid
* Flexbox
* Mobile-first workflow

## ✨ Features

* Responsive design for mobile, tablet, and desktop devices
* Light and dark theme toggle
* Interactive hover effects
* Clean and accessible UI
* Modern CSS layout using Grid and Flexbox

## 📚 What I Learned

While building this project, I strengthened my understanding of:

* Creating responsive layouts with CSS Grid and Flexbox
* Working with CSS custom properties for theme switching
* Implementing a dark/light mode toggle using JavaScript
* Structuring reusable and maintainable HTML and CSS

## 🔧 Continued Development

For future improvements, I would like to:

* Add smooth theme transition animations
* Improve accessibility with better keyboard navigation
* Optimize performance and CSS organization
* Rebuild the project using React or Vue for additional practice
